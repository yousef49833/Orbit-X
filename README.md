# Orbit-X // Holographic Space Mission Design Lab

Orbit-X is a mission control interface for planetary exploration planning, gravity simulation, landing-site analysis, and flight-director telemetry review.

## Run locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set `GEMINI_API_KEY` in a local `.env` file if you want live telemetry and flight-director responses.
3. Start the app:
   `npm run dev`

The app runs on http://localhost:3000 by default.
